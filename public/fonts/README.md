# Vazirmatn

Unmodified Arabic and Latin WOFF2 subsets, normal 400/500/700, copied from
`@fontsource/vazirmatn@5.3.0` (npm registry tarball; SHA-1
`d42f29907b9707130a6d500bd16b3a4896cf0831`). Package metadata identifies Google
Fonts source version v16, modified 2025-09-10. Fontsource is an asset source,
not an application dependency; no package scripts executed.

Copyright 2015 The Vazirmatn Project Authors
(https://github.com/rastikerdar/vazirmatn). Distributed under SIL OFL 1.1;
see the included `OFL.txt`. No renamed font aliases or external font requests.

CSS uses script ranges for common Persian/Arabic (including Persian letters,
digits and join controls) and Latin. Latin-ext and rare historic/Quranic ranges
fall back to system fonts. This is not a claim of native shaping or visual QA.
